# 🤖 AI Text Generator

An AI-powered **Text Generation Application** built using **Python, Streamlit, and Hugging Face Transformers**.
The application allows users to enter a prompt and generate AI-written text using a pre-trained language model.

## 🚀 Features

* ✍️ Generate text from a user-provided prompt
* 🤖 Uses a pre-trained Hugging Face language model
* 🖥️ Simple and interactive Streamlit interface
* ⚡ Generates text in real time
* 🎯 Easy-to-use text input
* 📄 Displays the generated text directly in the application

## 🛠️ Technologies Used

* **Python**
* **Streamlit** – For creating the web application
* **Hugging Face Transformers** – For text generation
